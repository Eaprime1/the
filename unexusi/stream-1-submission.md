## Mission Item 1: Latin Hub — Romance Language Distribution

**Seed sentence chosen:** *"Something arrives before it knows what it is."*

**Latin hub form:** *Aliquid advenit antequam se noscat.*
*(Something comes before it knows itself.)*

### Six-Branch Distribution

| Branch | Rendering | Emotional Body |
|--------|-----------|----------------|
| French | *Quelque chose arrive sans encore savoir ce qu'il est.* | Meditation already in progress. Distance. Reflection. |
| Italian | *Qualcosa arriva prima di sapere cosa è.* | The arrival IS the event. Warmth. Full presence. |
| Spanish | *Algo llega antes de saber lo que es.* | Urgent call. Assumes an audience. Reaches outward. |
| Portuguese | *Algo chega antes de saber o que é.* | Arrival already containing its own departure. Saudade. |

**Finding:** The same content produces six distinct emotional bodies. The choice of branch is a routing decision — matching what the concept needs to DO to the language that does it.

## Mission Item 2: Font and Accent Sensor Grammar

### The Five Primary Sensors

| Sensor | Reading | When |
|--------|---------|------|
| **bold** | Arrival / certainty / landed | The concept has resolved |
| *italic* | Motion / becoming / approach | The concept is forming |
| `code` | Mechanical / outside emotion | The concept as tool |
| CAPS | Announcement / THE mode / praeco | Formal introduction |
| ~~strikethrough~~ | Acknowledged departure (record, not erasure) | The thing that was |

### The Sensor Grammar — Five Rules

1. One primary sensor per word (combinations are possible but costly)
2. Sensors apply to emotional body, not literal meaning
3. CAPS announces — it does not emphasize (it is the praeco's voice)
4. Strikethrough is record, not erasure — it preserves trajectory
5. Code removes the concept from the emotional layer entirely

### The Sensor-to-Intake Mapping

```
*praesensio*    → italic   (sensing before arrival)
**cognitio**    → bold     (recognition / landing)
NOMINATIO       → CAPS     (formal naming)
```

The sensor grammar maps directly to the intake sequence.
