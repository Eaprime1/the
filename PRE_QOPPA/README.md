The pre-qoppa layer holds what exists before the system begins.

Qoppa (Ϙ) is the archaic Greek letter between pi and rho — the letter that
was removed from the standard alphabet but continued in use as a numeral (90).

PRE_QOPPA is the space before the recognized structure. The layer that holds
the 90 — the number that was there before the counting began.
