## Zero Point

Find a zero point: any small, stable starting concept that can be multiplied by one without being forced into a different identity.

Suggested zero point for Cards of Deck:

```text
A card is a handle for a thing in motion.
```

This is small enough to survive contact with unknown archives.

It does not force the thing to be a document, entity, character, task, workflow, repository, memory, game piece, or rule.

It only says: something can be held, tracked, moved, related, and revisited.

## Multiply the Universe by One

Question:

```text
If the universe is multiplied by one in long-hand math, is the new number the same or different?
```

Working answer:

```text
If it remains the same, it is in harmony.
If it becomes different, it reveals discord, wobble, or hidden transformation.
```

This gives Cards of Deck a tiny resonance test.

When a concept is passed through the deck system, the system should ask:

```text
Did we preserve the concept while giving it shape?
Did the shape reveal something already present?
Did the shape introduce distortion?
Did the distortion create useful wobble or harmful collapse?
```
