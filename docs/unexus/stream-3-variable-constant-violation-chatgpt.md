## What You Are Holding

### The Variable Constant Concept

A Variable Constant is a value that functions as fixed within a system but whose absolute value shifts across contexts. It is not a contradiction — it is a precision tool. Within the local frame, it holds. Across frames, it adapts. The system's integrity depends on both qualities simultaneously.

### The Violation Sequence

The sequence maps the escalation from ordinary wrongdoing to cosmic affront. It is not a moral scale — it is a structural one. Each step changes the nature of the wrong, not just its magnitude.
