# Font and Accent as Sensors

> Visual typographic elements as emotional fine-tuning instruments.
> Status: ♦ Diamond — concept named, grammar to be built

---

## The Claim

Bold, italic, accent marks, font color — these are not decoration.
They are sensors on the emotional layer.

A word in bold carries differently than the same word in italic.
A word in color is a word with a temperature.

This is not metaphor. This is grammar — an as-yet-unwritten grammar.

---

## Initial Readings

| Element | Preliminary Reading |
|---------|---------------------|
| **bold** | Weight / certainty / arrival — the thing that has landed |
| *italic* | Lean / motion / becoming — the thing still in approach |
| `code` | Precise / functional / non-emotional — the thing as mechanism |
| CAPS | Volume / announcement / THE mode |
| color (warm) | Temperature / urgency / proximity |
| color (cool) | Distance / reflection / French branch |
| accent marks | Specificity / foreign body in native text / the word that knows it came from elsewhere |

## Questions for Development

```
Is bold always arrival, or does it depend on context?
Is italic always motion, or can it be softness?
Can you construct a sentence where the same word means different things
  by appearing bold in one and italic in another?
Is there a grammar for combining sensors (bold + italic together)?
What does strikethrough mean? (the thing that was here and left)
What does underline mean? (the thing that has been chosen, or warned about)
What is the sensor for silence / absence?
```
