# Card Intake Protocol

> Every incoming concept, document, fragment, entity, or unknown is treated
> as a possible card. This protocol runs before sorting.

---

## The 10 Questions

For each incoming item, ask:

```
1.  What is the card?
    (name / first description)

2.  Which deck does it currently belong to?
    (Work / Play Wonka / Create Pandora / Synergy Spark / Unknown)

3.  Which suit-state is it showing now?
    (♦ Diamond-seed / ♣ Club-working / ♥ Heart-aethereal / ♠ Spade-pinnacle / Aperture)

4.  Is it a seed, working copy, pinnacle, interaction, or beyond-origin aperture?
    (confirm suit reading)

5.  Who or what is holding it?
    (player / agent / tool / unassigned)

6.  Is it in a hand, on a table, in a deck, or archived?
    (active / context / available / archive)

7.  What is its lineage?
    (where did it come from? what produced it?)

8.  What permission, condition, or choice marker governs its active use?
    (open / gated / conditions apply / unknown)

9.  Does it create synergy with other cards?
    (list related cards if known)

10. Does it require a new suit, new deck, or new rule?
    (escalate to fifth-suit aperture if yes)
```

---

## Drop States

After the 10 questions, assign a drop state:

```
0 = not yet in play — card is recognized but not active
1 = singular — card has one chosen active form
5 = expanded field — card is simultaneously active in multiple forms
```

## The Micro-Wobble Test

After sorting, pass the card through the micro-wobble test:

Multiply the concept by one (run it through the deck system).

Ask:
```
Did the concept return unchanged but clearer?   → in harmony
Did it return changed?                          → investigate the change
  Useful resonance?                             → keep
  Hidden truth surfacing?                       → integrate
  Translation artifact?                         → clean and retry
  Premature forcing?                            → return to Diamond
  Harmful distortion?                           → quarantine
  New suit request?                             → escalate to aperture
  New deck request?                             → escalate to dealer
```

## First Pass Principle

Do not force incoming material to fit the first draft.

Let the first draft create enough shape that the material can begin
revealing where it already belongs.

Treat all incoming material as Diamond until proven otherwise.
