## The Two Counting Systems

**Binary (2-prime):** the minimum meaningful distinction.

```
0 = is-not / absent / null / dark nessing
1 = is / present / active
```

There is no three in binary. Something either is, or it isn't.

**Pentadic (5-prime):** the first odd prime after 2. The number that
breaks symmetry.

```
0 = null / not yet / dark nessing
1 = singular / first emergence / seed
2 = paired / mirror / binary arrived
3 = triangle / minimum structure / relation
4 = quad / two pairs / balanced field
5 = quintessence / aperture / the fifth / beyond the four
```

Five doesn't close the circle the way four does. Four is a square — stable,
contained, symmetrical. Five is a fifth point that doesn't fit the quadrant.
Five is the aperture.

## 5 in Binary: The Frame

5 in binary is `101`.

```
1 · 0 · 1
outer | dark | outer
known | nessing | known
```

The structure of five-binary: two knowns framing a dark middle.
The zero is not nothing — it is the nessing space between two ones.

This is the shape of:
- A blackjack hand flanking an unknown dealer card
- A suite system framing the aperture (Diamond · Club · Heart · Spade · ∅ · Spade · Heart · Club · Diamond)

## Five States Applied to Cards

Every card occupies one of five states at any time:

```
0 — dark nessing     → in the shoe / unplayed / potential
1 — drawn            → surfaced / in hand / seed (♦ Diamond)
2 — active           → in play / being worked (♣ Club)
3 — in relation      → connected to other cards / social (♥ Heart)
4 — resolved         → pinnacle / placed / complete (♠ Spade)
5 — aperture         → beyond the four / dissolved / returned to sea
```

A card that reaches state 5 has not disappeared.
It has been played, resolved, contributed — and returned to dark nessing.

The five-binary is the full cycle: `0 → 1 → 2 → 3 → 4 → 5 → 0`.

Note: 5 and 0 are adjacent. The cycle closes.

## Drop-State Logic

In binary systems, a bit drops from 1 to 0 when it's cleared.
In five-binary, there are four possible drops:

```
5 → 0   return to dark nessing (healthy resolution)
4 → 3   pinnacle returns to aethereal (relation re-examined)
4 → 2   pinnacle returns to working (back-development)
3 → 2   aethereal returns to working (grounding needed)
```

Drops are not failures — they are recalibrations.
The only bad drop is skipping states: `4 → 0` without passing through 5.
That is a bust — forced dissolution without proper resolution.

## The Wobble Test in Five-Binary

Multiply a five-binary state by 1 — it must return unchanged.

```
0 × 1 = 0     dark nessing returns to dark nessing ✓
1 × 1 = 1     seed is still a seed ✓
5 × 1 = 5     aperture is still aperture ✓
```

If a concept doesn't survive the wobble — multiplied by one and it changes —
it hasn't found its true state yet. It's still nessing.
