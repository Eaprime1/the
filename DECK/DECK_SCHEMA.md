## Origin Statement

The work is not only building a deck.

The work is building Cards of Deck: a system where cards, suits, hands, players,
dealers, tables, and emergent synergies can track a universe of content without
collapsing the universe into one brittle structure.

---

## The Four Origin Suits

These are the base lifecycle states. Every card in the deck can be in one of
these states — or in motion between them.

```
♠  Spade of Aces   = Pinnacle    / container of containers / master archive
♦  Diamond of Aces = Seed        / origin / foundational / being born
♣  Club of Aces    = Working     / carbonite / active build / in motion
♥  Heart of Aces   = Aethereal   / interactive presence / relational / in conversation
```

A card's suit is not fixed. It reflects the card's current lifecycle state.

---

## The Fifth Suit Aperture ♞

The fifth suit is not suit number five.

It is the aperture — the point where suits beyond the origin four may resolve
from possibility into active deck structure.

```
1.25
 ^
 aperture / decimal gate / suit-drop point
```

New suits pass through the fifth suit aperture before becoming active.
The aperture prevents premature suit inflation.

## The Triadic Pattern

```
Deck      = the card universe / content architecture
Dealer    = routing / governance / state management
Players   = interacting entities / tools / teams / participants
─────────────────────────────────────────────────────
Synergy   = the emergent fourth / created through interaction
```

This pattern is the first sorting lens for all incoming material.

---

## Drop States

```
0 = not manifested / not in play
1 = singular chosen manifestation
5 = expanded field / multiple valid suit-states available
```

Only what has a valid permission, condition, or choice marker may drop
into the active deck. The ethical drop rule protects the system from
forcing concepts into active play before the correct condition exists.

