# Fifth Suit Aperture — The Gateway

> Suit state: Aperture / Unresolved Potential
> Symbol: ∘ (the point before resolution)
> Role: Gateway for beyond-origin suits

---

## What the Fifth Suit Is Not

The fifth suit is not suit number five.

It is the aperture — the gate through which all suits beyond the origin
four must pass before becoming active in the deck.

Without the aperture, new suits would collapse the four-suit anchor.
With the aperture, the deck can expand without breaking its foundation.

---

## The Aperture as Mathematical Point

```
1.25
 ^
 aperture / decimal gate / suit-drop point
```

The decimal point in 1.25 is the aperture.

The whole numbers (1, 2, 3, 4) are stable suits.
The decimal position is the gate where new suits form.

A concept that arrives wanting to be a new suit must first:
1. Pass through the aperture (prove it cannot fit within the origin four)
2. Receive a drop-state marker (0, 1, or 5)
3. Be given a lineage (where did it come from?)
4. Be tested against the triadic pattern

Only then does it become a real suit.

---

## Drop States at the Aperture

```
0 = not manifested — the suit-concept exists but is not active
1 = singular — one specific suit has been chosen and activated
5 = expanded field — multiple valid suit-states are simultaneously available
```

The aperture holds suits in state 0 until conditions are met for 1 or 5.

---

## The 2-Prime and 5-Prime

```
2-prime = either / or     →  is | is-not
5-prime = zero/one/five   →  not-yet | singular | expanded-suit-field
```

The aperture operates on 5-prime logic.

A suit-candidate is not simply present or absent. It is:
- not-yet manifested (0)
- chosen as singular (1)
- or available as expanded field (5)

## The Aperture Is Itself Aethereal

The fifth suit aperture uses the ∘ symbol as a marker, though it is not a playable suit in the standard deck.
It cannot be played as a card.
