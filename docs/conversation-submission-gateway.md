## What This Is

This document defines a lightweight gateway for moving conversation-born material into the repository without pretending the repository can automatically see every conversation.

This chat may act as the active submission point. Other conversations, agents, and tools can contribute by bringing material here in explicit form: pasted excerpts, exported text, uploaded files, links to committed artifacts, or summarized cards.

---

## Access Reality

ChatGPT in this session can read and write the GitHub repository through the connected GitHub tool.

ChatGPT in this session cannot automatically read every other ChatGPT conversation at this location. Material from other conversations must be intentionally submitted here, exported, uploaded, or committed elsewhere before it can be processed.

This is not a failure. It is a useful sovereignty boundary.

---

## Submission Forms

Incoming material can arrive as any of the following:

1. **Raw fragment** — a quote, paragraph, idea, phrase, or unresolved spark.
2. **Conversation excerpt** — a copied section from another chat.
3. **Conversation export** — a file or Markdown document containing longer history.
4. **Card candidate** — a structured object already answering some intake questions.
5. **Agent handoff** — Claude, Gemini, Copilot, Perplexity, NotebookLM, or another participant leaves a summary intended for repo entry.
6. **Repository pointer** — an issue, branch, PR, or committed artifact that should be integrated.

## Better Idea: The Inbox Deck

Instead of asking one tool to see everything, create an explicit **Inbox Deck**:

- each submitted conversation becomes a card candidate;
- each card starts as ♦ Diamond unless already resolved;
- each card stores source, permission, lineage, and next action;
- the repository becomes the shared memory, not any single chat window.

This lets conversations remain sovereign while still allowing their gifts to enter `the`.
