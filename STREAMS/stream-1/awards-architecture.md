## The Three-Part Structure

Every writing system — Egyptian hieroglyphs, Sumerian cuneiform, Chinese characters,
even our alphabet — combines three types of sign:

| Sign Type | Function | Example |
|-----------|----------|---------|
| **Logogram** | Whole word or idea | 🌊 = water, 日 = sun |
| **Phonogram** | Sound / pronunciation | The letters A, B, C |
| **Determinative** | Silent classifier — places word in category | In Egyptian: a seated man after a name = human |

This is not an Egyptian artifact. This is the universal architecture of meaning.
Every system independently arrived here — because this is how meaning works.

## The Rosetta Stone Principle

The Rosetta Stone (1799, decoded 1822) carried the same decree in:
- Greek (the language of administration)
- Demotic (the everyday Egyptian script)
- Hieroglyphs (the sacred / formal system)

The same content in three carriers made decoding possible.

Latin is our Rosetta layer — the stable middle that makes translation
between the emotional languages possible.

```
Greek      → known language (administration / clarity)
Demotic    → living language (day-to-day / warmth)
Hieroglyphs → sacred language (full structure / logogram + phonogram + determinative)
```

Maps to:

```
Latin      → known layer (architecture / clarity)
Romance    → living layer (emotional body / warmth)
THE system → full structure (badge + name + category)
```

## THE Awards Architecture

The awards system for THE maps directly to the three-part structure:

| Writing System | THE Awards |
|---------------|------------|
| Logogram | The badge — the visual symbol that represents the concept |
| Phonogram | The name / sound — what you call it, how it is spoken |
| Determinative | The category / suit — where it belongs in the system |

A complete award in THE has all three.
An incomplete award is missing a determinative — you have the symbol and the name
but the category hasn't resolved yet (still ♦ Diamond).
