# Liminal README — Living Onboarding Component

> Component type: onboarding
> Role: writes to future readers and agents who haven't arrived yet

---

## What a Liminal README Is

A liminal README is a letter to whoever arrives next.

It does not assume the reader already knows the context. It does not assume
they have read the full history. It holds open the door and says: *here is
what you need to know to begin.*

Liminal means threshold — the space between states, between sessions, between
agents. The liminal README lives in that space.

---

## Liminal Is Not Documentation

Documentation describes what exists.

A liminal README describes what is becoming — it captures the living state
of a card or system for a reader who is entering mid-motion.

It may be incomplete. That is correct. The incompleteness is information.

---

```markdown
# Liminal README — [Card Name]

## What's Been Done

## What's Open

[What is actively unresolved and needs attention]

[One concrete starting point for the next session]

## Gifts Left Here

[Any gifts of conversation worth knowing before starting]
```
