# Contributing to THE

## Quick start

1. Read `AGENTS.md`
2. Read `NAVIGO.md`
3. Check `turns/log.md`
4. Create a branch for one workstream
5. Open a pull request

## Branch guidance

- Prefer branching from `radix` when present.
- Never push directly to `main`.
- Use focused branch names:
  - `docs/...`
  - `chore/...`
  - `fix/...`

## Pull request guidance

- Keep one clear purpose per PR.
- Use the PR template.
- Note any filename/path normalization.
- Include validation output when relevant.

## Documentation guidance

- Preserve project voice and terminology.
- Keep source titles in document bodies when filenames are normalized.
- Use repository-safe filenames.
