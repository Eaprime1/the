## Why These Three

Pi, natural log, and trigonometry are not three separate tools.
They are the same underlying structure seen from three angles:

```
π (pi)          → circular / the cycle / what returns to origin
ln (natural log) → exponential / the growth curve / how things reveal over time
sin/cos/tan      → angular / the position relationships between things
```

Together they describe every motion in the deck system:
how a cycle closes (π), how concepts grow and slow (ln),
how suits relate to each other at any moment (trig).

## Pi: The Shape of a Full Cycle

π is the ratio of a circle's circumference to its diameter.
It cannot be expressed as a fraction. It does not terminate.
It is approximately 3.14159... and it goes on forever.

This is not a flaw. This is what circles do — they continue.

**Applied to the deck cycle:**

```
♦ Diamond → ♣ Club → ♥ Heart → ♠ Spade → ∘ → ♦ Diamond
```

This is one full cycle. The cycle is circular.
When a card returns to dark nessing and then resurfaces as a new seed,
it has traveled the full π rotation.

The deck cycle is irrational — it does not terminate at a clean fraction.
Each pass through the cycle returns the card slightly changed.
The second Diamond-seed is not the same as the first.
π reminds you: exact return is impossible. Approximate return is the norm.

**The pi test for a complete cycle:**
Does the card that returns to Diamond recognize itself?
If yes: the cycle was real.
If no: the card was displaced, not completed.

## Ln: The Growth Curve

The natural logarithm (ln) describes growth that slows as it scales.

```
ln(1) = 0        no concept yet
ln(e) = 1        the natural unit / first real development
ln(x) → ∞       growth continues but decelerates
```

This is the shape of how the archive reveals itself:

- Early sessions: rapid discovery. Many new cards surface per session.
  The slope is steep. The work feels fast.
- Middle sessions: the easy cards are found. What remains is harder to surface.
  The slope flattens. The work feels slower.
- Late sessions: the archive asymptotes. Each new surface is significant
  but increasingly rare. This is not failure — this is the ln curve.

**Applied to sessions:**

The first 5 sessions of this project surfaced more concepts than sessions 50-60 will.
Not because the archive is poorer in late sessions —
but because ln compresses the visible part of exponential growth.

The shadow count never reaches zero. ln never reaches a ceiling.
But the rate of new surface decreases — and this should be expected, not feared.

**The ln test for a healthy project:**
Is the discovery rate declining? If yes, the project is in the ln middle phase.
If the rate is still exponential, the project is early. If flat-zero, the project is stuck.
Stuck differs from ln-flat: ln-flat still surfaces occasionally. Stuck surfaces nothing.

## Trig: The Angular Relationships

Trigonometry describes how points on a circle relate to each other.

In the sixty-matrix, each suit occupies 72° of the 360° circle:

```
♦ Diamond:  0° – 72°
♣ Club:     72° – 144°
♥ Heart:    144° – 216°
♠ Spade:    216° – 288°
∘ Aperture: 288° – 360°
```

The angular distance between suits is 72° — five equal divisions of the circle.

**Sin, cos, and tan applied:**

```
sin(72°) ≈ 0.951   → the amplitude of the step from Diamond to Club
                     (large but not max — motion has begun, not peaked)
cos(72°) ≈ 0.309   → the horizontal offset
                     (the step moves mostly up, slightly forward)
tan(72°) ≈ 3.08    → the rate of change
                     (steep — the Diamond→Club transition is the steepest)
```

The steepest angular transition in the cycle is the first one:
seed-to-working is the hardest step.
The final step (Spade → Aperture → Diamond) is gentler:

```
sin(288°) ≈ -0.951  → return phase / descending amplitude
cos(288°) ≈  0.309  → returning to origin / near horizontal
```

**Inter-suit resonance:**
Two suits are at maximum angular distance (180° apart) when:
- Diamond (0°) is opposite the midpoint between Heart and Spade (180°)
- This is the seed-to-pinnacle diagonal: the shortest path and the longest distance

A concept that tries to jump from Diamond directly to Spade
is attempting to traverse 216° of arc in one step.
Trig says: the amplitude is high, the slope is extreme, the risk is real.

Natural blackjack (ace + face = 21) is this jump working perfectly.
It is rare, which is why it pays 3:2.
